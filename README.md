# FitLog — Workout Library

FitLog is a dark, no-nonsense gym companion web application built for fitness enthusiasts to plan and track their daily lifts. 

## 🚀 Technologies Used
* Next.js (App Router)
* Tailwind CSS
* Lucide React (Icons)
* Context API (State Management)
* LocalStorage (Data Persistence)

## ✨ Key Features
1. **Dynamic Workout Library:** View all major muscle group workouts in a responsive grid fetched from the API.
2. **Smart Search & Sort:** Easily find workouts by name or category and sort them by duration, calories, or rating.
3. **Daily Plan Management:** Add up to 5 exercises to "Today's Plan" with live metrics (Exercises, Minutes, Calories).
4. **Mark as Done:** Keep track of your progress by marking completed workouts.
5. **Save for Later & Persistence:** Bookmark workouts and keep your plan saved even after page reloads using LocalStorage.
