# FitLog — Workout Library 🏋️‍♂️

> FitLog is a dark, no-nonsense gym companion web application built for fitness enthusiasts to plan and track their daily lifts.

**🔗 [Live Demo](https://fit-log-zeta-three.vercel.app/)**

## 🚀 Technologies Used
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **State Management:** Context API
- **Data Persistence:** LocalStorage

## ✨ Key Features
- **Dynamic Workout Library:** View all major muscle group workouts in a responsive grid fetched from the API.
- **Smart Search & Sort:** Easily find workouts by name or category and sort them by duration, calories, or rating.
- **Daily Plan Management:** Add up to 5 exercises to "Today's Plan" with live metrics (Exercises, Minutes, Calories).
- **Mark as Done:** Keep track of your progress by marking completed workouts.
- **Save for Later & Persistence:** Bookmark workouts and keep your plan saved even after page reloads using LocalStorage.
